=== Renderer::Input

Renders input text boxes. Many other renderers use this one e.g. `numeric`, `date` etc.

This is the default renderer. If a UI Rule does not specify a specific renderer, this one will be used.

Go to link:/development/generators/ui_previews[Preview an input field] to test attributes and preview an input field.

`:numeric` (allows **decimals**) renders with numeric inputs that only accept digits (and `-` and `.`) and have step-up and step-down arrows.

`:url` and `:email` are rendered with patterns that check for valid formats. Note :url must include the protocol (`http:` etc.)

=== Renderer::RadioGroup

The radio group takes a set of options with unique values and returns the value of one of them. The options are similar to those for a `select`.

[NOTE]
====
**NB:** To make code more maintainable, the best practice is to make the value the same as the caption, but all lowercase and with underscores instead of spaces,

e.g.
[source,ruby]
----
[['Turn Left', 'turn_left'], ['Go Around', 'go_around']]
----
====

An example of checking the radio group value:
[source,ruby]
----
case params[:xform][:yradio]
when 'turn_left'
  do_go_left_things(params[:xform])
when 'go_around'
  do_go_around_things(params[:xform])
else
  raise "#{params[:xform][:yradio]} has not been properly implemented!"
end
----

NOTE: The way this control is implemented, there will always be a value returned from the radio group. If the underlying field is `nil`, the first option will be selected in the page. This can be confusing if a form is opened and checked for the value but not saved as this might only match what is in the database once the form is saved.

=== Renderer::SelectMultiple

Renders a select box.

[NOTE]
====
In params, this control will always include an empty string in the returned array. You can use the helper method `strip_multiselect_blanks` to get rid of the empty string.
[source,ruby]
----
params = { :_method => "PATCH",
           :organization => { :short_description => "4P",
                              :role_ids => ["", "19"] }
         }
# => { :_method => "PATCH",
#      :organization => { :short_description => "4P", :role_ids => ["", "19"] } }
strip_multiselect_blanks(params[:organization])
# => { :short_description => "4P", :role_ids => ["19"] }
----
====

|===
|attribute |description |possible values |default

|:caption
|The label text
|any text
|The field name with underscores converted to spaces
and all words start with initial capital letter.

|:sort_items
|Should the items be sorted alphabetically. Set this to false if the supplied options are already in a desired sequence (e.g. descending order).
